# Генератор экзаменационных билетов

Консольное приложение на Python для автоматической генерации номеров экзаменационных билетов и ведения журнала в файле Excel (`journal.xlsx`).

Разработано в точном соответствии с техническим заданием лабораторной работы.

## 🚀 Возможности

- **Перехват клавиши ESC:** Для завершения работы приложения достаточно нажать клавишу `ESC` при ожидании ввода.
- **Посимвольный ввод с поддержкой Unicode:** Корректная обработка клавиши `Backspace` и поддержка как русских, так и латинских символов.
- **Валидация:** Пустые строки или строки, состоящие только из пробелов, не принимаются — приложение повторно запрашивает ввод. Пробелы по краям автоматически обрезаются.
- **Генерация билетов:** Случайный выбор билета в диапазоне от 1 до 20 включительно.
- **Надежное сохранение:** Файл `journal.xlsx` сохраняется сразу после ввода каждого студента, исключая потерю данных при аварийном завершении.
- **Защита от блокировки файлов:** Если файл `journal.xlsx` открыт в Excel, приложение выводит предупреждение и ждет закрытия файла, не падая с ошибкой.

## 📋 Формат таблицы `journal.xlsx`

| Last name | First name | Номер билета | Дата и время |
| :--- | :--- | :---: | :---: |
| Иванов | Иван | 7 | 2026-09-23 22:15:00 |

## 🛠️ Установка и запуск

1. Убедитесь, что установлен Python 3.10+:
   ```bash
   python --version
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите приложение:
   ```bash
   python main.py
   ```

## 🧪 Запуск автоматических тестов

```bash
python -m unittest test_excel.py
```
