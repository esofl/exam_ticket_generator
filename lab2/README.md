# Лабораторная работа №2: Десктопное UI-приложение «Генератор экзаменационных билетов»

Десктопное приложение с графическим интерфейсом на Python (Tkinter/ttk) для автоматизированного распределения экзаменационных билетов студентам, считывания исходных данных из файлов Excel и Word и ведения хронологического журнала результатов.

Разработано в точном соответствии с техническим заданием ([`TZ2.md`](file:///E:/Downloads/TZ2.md)).

---

## 🚀 Основные возможности и особенности

1. **Входные данные:**
   - `students.xlsx`: группы определяются именами листов книги Excel; со 2-й строки считываются Фамилия (Колонка A) и Имя (Колонка B).
   - `tickets.docx`: парсинг структуры экзаменационных билетов (`Билет N`) и 3 нумерованных вопросов к каждому билету (`N. текст`).
2. **Интерфейс (GUI на Tkinter/ttk):**
   - Первый выпадающий список заполняется группами из `students.xlsx`.
   - Второй список («Фамилия Имя») заполняется динамически при выборе группы.
   - Кнопка «Сгенерировать билет» неактивна до тех пор, пока не выбраны и группа, и студент.
   - Окно результата («Ваш билет № N» и 3 вопроса) открывается модально и закрывается по клавише **`ESC`** без завершения работы приложения.
3. **Идемпотентность и назначение билетов:**
   - Если студент уже присутствует в журнале `results.xlsx`, ему возвращается номер билета из его **самой первой** записи. Новый номер не генерируется, а в журнал добавляется строка с отметкой `Повтор = "да"`.
   - Если студента еще нет в журнале — случайным образом выбирается билет из доступных, а в журнал пишется запись с `Повтор = "нет"`.
4. **Надежное ведение журнала `results.xlsx`:**
   - Создается автоматически при первом запуске (колонки: *Группа, Фамилия, Имя, Номер билета, Дата и время, Повтор*).
   - Запись выполняется **немедленно** после генерации, а не при выходе.
   - Полная хронологическая история сохраняется (старые строки не модифицируются и не удаляются).
5. **Отказоустойчивость:**
   - Отсутствие `students.xlsx` или `tickets.docx` обрабатывается понятным сообщением об ошибке без аварийного падения.
   - Выбор пустой группы оставляет список студентов пустым, кнопка неактивна, исключений нет.
   - Защита от блокировки: если `results.xlsx` открыт в Excel, приложение отображает диалог повторной попытки сохранения.
   - Устойчивость к поврежденным билетам: билеты с < 3 вопросов в `tickets.docx` пропускаются с предупреждением в лог, приложение продолжает работать с валидными билетами.

## 🛠️ Установка и запуск

1. **Клонирование репозитория и переход в папку проекта:**
   ```bash
   cd E:\exam_ticket_generator
   ```

2. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   ```

3. **(Опционально) Генерация демонстрационных файлов данных:**
   ```bash
   python create_sample_data.py
   ```
   *Создает демонстрационные файлы `students.xlsx` (с группами и студентами) и `tickets.docx` (с билетами и вопросами).*

4. **Запуск приложения с графическим интерфейсом:**
   ```bash
   python main.py
   ```
