# Лабораторная работа №1: Консольный генератор экзаменационных билетов

Консольное приложение на Python для автоматической генерации номеров экзаменационных билетов и ведения журнала в файле Excel (`journal.xlsx`).

Разработано в точном соответствии с техническим заданием ([`TZ1.md`](file:///C:/Users/sidekick/Desktop/TZ1.md)).

---

## 🚀 Возможности и соответствие ТЗ

1. **Запуск и подсказка:** при старте выводится `Для выхода нажмите ESC.`
2. **Ввод данных:**
   - Запрос `Last name: ` с подтверждением по Enter.
   - Запрос `First name: ` с подтверждением по Enter.
   - Перехват клавиши `ESC` в любой момент ожидания ввода завершает работу приложения.
   - Посимвольный ввод на Windows через `msvcrt` с поддержкой клавиши Backspace и символов Unicode (кириллица и латиница).
   - Валидация: пустые строки или строки только из пробелов не принимаются, запрос повторяется; пробелы по краям обрезаются.
3. **Генерация билета:**
   - Случайный выбор номера в диапазоне от 1 до 20 включительно.
   - Вывод в консоль: `Билет № 7`.
4. **Надежное сохранение:**
   - Запись дописывается в конец `journal.xlsx` **сразу после каждого студента**, исключая потерю данных при закрытии или сбое.
   - Если файл отсутствует — создается автоматически со стандартной шапкой.
5. **Защита от блокировки файлов:**
   - Если файл `journal.xlsx` открыт в Excel, приложение выводит предупреждение и ждет закрытия файла, не падая с ошибкой.

## 🛠️ Установка и запуск

1. Перейдите в папку `lab1`:
   ```bash
   cd lab1
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите приложение:
   ```bash
   python main.py
   ```
