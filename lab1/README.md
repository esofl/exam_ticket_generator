# Лабораторная работа №1: консольный генератор экзаменационных билетов

## Что это

Консольное приложение на Python. Преподаватель по очереди вводит фамилию и имя студента, приложение выдаёт случайный номер билета (1–20) и **сразу** дописывает строку в журнал Excel `journal.xlsx`. Клавиша **ESC** в любой момент ввода завершает работу.

Код построен по принципам **SOLID**: сценарий работы не знает ни про консоль, ни про Excel — он работает через интерфейсы, а конкретные реализации собираются в `main.py`.

| pip-зависимости | `openpyxl` | ставятся из `requirements.txt` |

## Установка и запуск

```powershell
git clone https://github.com/esofl/exam_ticket_generator.git
cd exam_ticket_generator\lab1
python -m pip install -r requirements.txt
python main.py
```

> Запускайте в обычном терминале Windows (PowerShell / cmd / Windows Terminal). Во встроенных консолях некоторых IDE `msvcrt.getwch()` не получает нажатия клавиш — тогда используйте внешний терминал.

## Как пользоваться

```text
Для выхода нажмите ESC.
Last name: Иванов
First name: Иван
Билет № 7
Last name: Петров
First name: Пётр
Билет № 13
Last name: <ESC>
Работа приложения завершена.
```

- Пустая строка или строка из пробелов не принимается — запрос повторяется.
- Пробелы по краям обрезаются, поддерживаются кириллица и Backspace.
- После каждого студента строка сразу сохраняется в `journal.xlsx` (в папке, из которой запущено приложение). Файл создаётся автоматически с шапкой.
- Если `journal.xlsx` открыт в Excel, приложение не падает: просит закрыть файл и нажать Enter, затем повторяет запись.

### Формат `journal.xlsx`

| Last name | First name | Номер билета | Дата и время |
| :--- | :--- | :---: | :---: |
| Иванов | Иван | 7 | 2026-11-17 10:15:00 |

## Сценарий демонстрации на защите

1. `python main.py` → ввести 2–3 студентов → показать номера билетов.
2. Открыть `journal.xlsx` в Excel — строки уже там, хотя приложение ещё работает.
3. Не закрывая Excel, ввести ещё одного студента → появится просьба закрыть файл; закрыть Excel, нажать Enter → запись сохранена.
4. Нажать пустой Enter → запрос повторяется. Нажать ESC → приложение завершается.
5. Запустить тесты (ниже).

## Архитектура и SOLID

```text
main.py ──собирает──► ExamSession(reader, output, generator, journal)
                          │ зависит только от интерфейсов (protocols.py)
        ┌─────────────────┼──────────────────┬───────────────────┐
  ConsoleInput     ConsoleOutput   RandomTicketGenerator    ExcelJournal
 (console_input.py)                (ticket_generator.py)   (excel_manager.py)
```

| Модуль | Ответственность | Принцип |
| :--- | :--- | :--- |
| `protocols.py` | Интерфейсы `InputSource`, `Output`, `TicketGenerator`, `Journal` | **ISP** — маленькие узкие интерфейсы, **DIP** — сценарий зависит от них |
| `exam_session.py` | `ExamSession` — только порядок шагов (ввод → билет → запись) | **SRP** |
| `ticket_generator.py` | `RandomTicketGenerator` — только выбор номера | **SRP**, **LSP** — любая реализация `next_ticket()` подставляется без изменений сценария |
| `excel_manager.py` | `ExcelJournal` — только хранение; о блокировке файла сообщает через колбэк `on_locked`, сам ничего не печатает | **SRP**, **DIP** |
| `console_input.py` | Посимвольный ввод с ESC + адаптеры `ConsoleInput` / `ConsoleOutput` | **SRP** |
| `main.py` | Composition root — собирает реализации | **OCP** — замена консоли или хранилища меняет только этот файл |

## Частые проблемы

| Симптом | Решение |
| :--- | :--- |
| `ModuleNotFoundError: openpyxl` | `python -m pip install -r requirements.txt` |
| ESC/клавиши не реагируют | запустите в обычном терминале Windows, а не во встроенной консоли IDE |
| «Файл открыт в другой программе» | закройте `journal.xlsx` в Excel и нажмите Enter |
